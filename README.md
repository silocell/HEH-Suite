# Launchpad Suite

Write, Grid, Present and Notebook - the Homework Launchpad's own office apps, at
https://suite.civilinitiatives.org. Sign-in is shared with the Launchpad.

- `write/` documents (opens and saves .docx)
- `grid/` spreadsheets (opens and saves .xlsx and .csv)
- `present/` slides (opens and saves .pptx)
- `notebook/` notes, checklists and drawing
- `office/` the shared parts: saving, the Files window, safe HTML, JSZip

Files are saved in the `office_files` table, which only each file's owner can read.
